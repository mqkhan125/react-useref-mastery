🚀 React useRef() Complete Notes


1. Core Concepts (What is useRef?)
a. Value Persistence: A useRef variable persists its value across component re-renders.
b. No Re-rendering: Changing the value of ref.current does not trigger a component re-render.
c. Comparison with Normal Variables: Normal variables are re-initialized and lose their values
 on every re-render, whereas useRef retains its data throughout the component lifecycle.


2. Structure & Syntax
a. Initialization: When you create a ref, it returns a mutable object with a current property.
example : 
const x = useRef(0); // Returns: x = { current: 0 }
b. Accessing Value: You can read or update the value directly using x.current.


3. Lifecycle of a Ref (3 Essential Steps)
i. Create: Define the ref using const myRef = useRef(null);.
ii. Link/Attach: Connect the ref to a JSX element using the ref attribute (e.g., <button ref={myRef}>).
iii. Access: Manipulate the DOM node or value using myRef.current.


4. Primary Use Cases
a. Direct DOM Access: Directly manipulate DOM elements without using vanilla JavaScript methods like document.getElementById().
b. Mutable Data Storage: Store data that changes over time but shouldn't cause a re-render when it updates.


5. Common Real-World Implementations
a. DOM Controls: Focusing a text input, scrolling to specific elements, or controlling HTML5 media (Video/Audio play/pause).
b. Style Manipulation: Dynamically changing DOM elements' properties or styles (like toggling background colors).
c. Side-Effect Management: Safely storing and clearing interval or timeout IDs (setInterval / setTimeout).
d. State Tracking: Keeping track of the previous state's value or calculating the total render count of a component.
